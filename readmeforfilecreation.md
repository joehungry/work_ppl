1. write `dir <directory name>` to specify directory name
2. write `open <filename>` to handle file
3. specify filetype by `filetype <filetype>`
```
available filetypes
1. diary (d) (not a filetype, but can handle diaries more robustly)
2. goal (g) (for writing session goals, overwrites everytime, and has numbers next to every newline)
3. none (n) when wanting to handle files more robustly
```
4. `F'w` to write in file
5. `F+'<thing to write>`
6. `F-` to delete one key
7. `F'<number>` to change index number
8. `F'c` to overwrite in file
9. `F't` to go to first element
10. `F'r` to go to last element
11. `F'sv` to save (it's not going to automatically save)
